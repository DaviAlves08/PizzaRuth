## 📖 Sobre o Projeto

O **Pizza Ruth** foi desenvolvido para uma atividade na **ETEC Dra. Ruth Cardoso**, com o objetivo de criar um site completo de pizzaria. A inspiração veio do PizzaHut, resultando em uma aplicação full-stack com área do cliente e painel administrativo.

## 🖥️ Funcionalidades

### Área do Cliente
- 🏠 **Home** — Vitrine principal com as pizzas e bebidas do restaurante
- 🍕 **Cardápio** — Listagem de pizzas e bebidas disponíveis
- 🛒 **Carrinho de Compras** — Adição e gerenciamento de itens do pedido
- 📝 **Cadastro** — Criação de conta de usuário
- 🔐 **Login** — Autenticação de clientes
- 👤 **Meus Dados** — Visualização dos dados do perfil

### Área do Admin
- ➕ **Cadastro de Itens** — Adição de novas pizzas e bebidas ao cardápio
- ✏️ **Edição de Itens** — Atualização de informações dos produtos
- 🗑️ **Exclusão de Itens** — Remoção de produtos do cardápio

## ⚙️ Como Rodar a Aplicação

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- [Git](https://git-scm.com/) instalado

### Instalação

```bash
# Clone o repositório
git clone https://github.com/DaviAlves08/PizzaRuth.git

# Acesse a pasta do projeto
cd PizzaRuth
```

### Rodando o Back-End

```bash
# Acesse a pasta do servidor
cd server

# Instale as dependências
npm install

# Inicie o servidor
npm start
```

### Rodando o Front-End

```bash
# Acesse a pasta do cliente (em outro terminal)
cd client

# Instale as dependências
npm install

# Inicie a aplicação
npm run dev
```

> A aplicação estará disponível em `http://localhost:5173`
